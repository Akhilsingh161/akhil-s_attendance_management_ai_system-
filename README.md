# AI Attendance Management System

A Python-based attendance management system that combines AI-powered command interpretation with automated attendance tracking and reporting.

## Features
- AI-based attendance commands using Hugging Face
- Individual and average attendance calculations
- Detection of students below a specified attendance threshold
- Marking and removing attendance records
- JSON-based data storage
- Local command fallback when AI is unavailable

## Technologies
Python | Hugging Face | JSON | GitHub

## Installation

```bash
git clone https://github.com/Akhilsingh161/akhil-s_attendance_management_ai_system-.git
cd akhil-s_attendance_management_ai_system-
pip install -r requirements.txt
```

Configure your `HF_TOKEN` and `HF_MODEL` in a local `.env` file, then run:

```bash
python app.py
```

To simplify attendance management through Python automation and AI-based natural-language processing.
